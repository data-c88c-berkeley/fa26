Iterators

An iterable is any value that can be iterated through, or gone through one item at a time. One construct that we've used to iterate through an iterable is a for statement:

for item in iterable:
    # do something

In general, an iterable is an object on which calling the built-in iter function returns an iterator. An iterator is an object on which calling the built-in next function returns the next value.

For example, a list is an iterable value.

>>> s = [1, 2, 3, 4]
>>> next(s)       # s is iterable, but not an iterator
TypeError: 'list' object is not an iterator
>>> t = iter(s)   # Creates an iterator
>>> t
<list_iterator object ...>
>>> next(t)       # Calling next on an iterator
1
>>> next(t)       # Calling next on the same iterator
2
>>> next(iter(t)) # Calling iter on an iterator returns itself
3
>>> t2 = iter(s)
>>> next(t2)      # Second iterator starts at the beginning of s
1
>>> next(t)       # First iterator is unaffected by second iterator
4
>>> next(t)       # No items left!
StopIteration
>>> s             # Original iterable is unaffected
[1, 2, 3, 4]

You can also use an iterator in a for statement because all iterators are iterable. But note that since iterators keep their state, they're only good to iterate through an iterable once:

>>> t = iter([4, 3, 2, 1])
>>> for i in t:
...     print(i)
4
3
2
1
>>> for i in t:
...     print(i)

There are built-in functions that return iterators. These built-in Python sequence operations are said to compute results lazily.

>>> m = map(lambda x: x * x, [3, 4, 5])
>>> next(m)
9
>>> next(m)
16
>>> f = filter(lambda x: x > 3, [3, 4, 5])
>>> next(f)
4
>>> next(f)
5
>>> z = zip([30, 40, 50], [3, 4, 5])
>>> next(z)
(30, 3)
>>> next(z)
(40, 4)

Here are the iterator functions we use in this course:

Function Returns
iter(iterable) An iterator over the items of iterable
next(iterator) The next item in iterator
map(func, iterable) An iterator over func(x) for each x in iterable
filter(func, iterable) An iterator over each x in iterable for which func(x) is true
zip(first, second) An iterator over co-indexed (x, y) pairs from first and second
reversed(sequence) An iterator over the items of sequence in reverse order

To view the contents of an iterator, place its items into a container with list, tuple, or sorted.

>>> list(map(lambda x: x * x, [3, 4, 5]))
[9, 16, 25]
>>> tuple(reversed([3, 4, 5]))
(5, 4, 3)
>>> sorted(filter(lambda x: x != 4, [5, 4, 3]))
[3, 5]

Lazy or Eager?

Calling map doesn't call the function it's given. Instead, it returns an iterator that calls the function on one item each time next is called. Here's a function that prints a line each time it's called, so that you can see when that happens (from Section 2.8 of Composing Programs):

>>> def double_and_print(x):
...     print('***', x, '=>', 2 * x, '***')
...     return 2 * x
>>> s = [3, 4, 5, 6]
>>> doubled = map(double_and_print, s)
>>> evens = filter(lambda y: y % 4 == 0, doubled)
>>> next(evens)
>>> list(doubled)
>>> list(evens)

As a group, predict what Python displays after each of the last three lines. Then, discuss: what would be different if doubled were defined as the list [double_and_print(x) for x in s] instead?
