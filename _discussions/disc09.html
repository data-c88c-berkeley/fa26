  • __init__(self, product, price): A vending machine sells a single product at a fixed price. It starts with a stock of 0 and a balance of $0.
  • restock(self, n): Add n to the stock and report the new stock level.
  • add_funds(self, n): If out of stock, refuse the money and return it. Otherwise, add n to the current balance and report it.
