Linked Lists

A linked list is a Link object or (), the empty tuple.

You can make a new Link object by calling Link. The second argument to Link should always be a a linked list (another Link object or ()):

  • Link(4) makes a linked list containing 4.
  • Link(4, Link(5)) makes a linked list containing 4 and 5.
  • Link(4, 5) is not well formed because the second argument is not a linked list. Don't do that!
