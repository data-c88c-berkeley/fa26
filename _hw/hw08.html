Q1: Every Other

Implement every_other, which takes an iterator t and returns an iterator over every other item of t: the items at indices 0, 2, 4, and so on.

To find out the index of each item, zip t with count(). The count function from Python's itertools module (already imported for you) takes no arguments and returns an iterator over the integers 0, 1, 2, 3, ... that never runs out. So zip(count(), t) is an iterator over (index, item) pairs, one for each item of t:

>>> pairs = zip(count(), iter(['a', 'b', 'c']))
>>> next(pairs)
(0, 'a')
>>> next(pairs)
(1, 'b')

Then keep only the pairs with even indices, and turn each pair back into its item.

Important: every_other must be lazy: it should take an item from t only when a caller asks the returned iterator for an item that requires it. Calling every_other(t) shouldn't take any items from t at all. Python's zip, filter, and map are lazy in exactly this way, so build your answer from them instead of building a list.

from collections.abc import Iterator  # t: Iterator[int] means t is an iterator that yields integers
from itertools import count


def every_other(t: Iterator[int]) -> Iterator[int]:
    """Return an iterator over the items of t at even indices: the first,
    third, fifth, ... items.

    >>> def noisy(x):  # Print each item as it is taken from t
    ...     print('took', x)
    ...     return x
    >>> t = map(noisy, [10, 11, 12, 13, 14, 15])
    >>> s = every_other(t)  # Nothing is taken from t yet
    >>> next(s)             # Only 10 is taken from t
    took 10
    10
    >>> next(s)             # 11 and 12 are taken from t
    took 11
    took 12
    12
    >>> next(t)             # 13 has not been taken by every_other
    took 13
    13
    >>> list(every_other(iter([5, 6, 7, 8, 9])))
    [5, 7, 9]
    >>> list(every_other(iter([1, 2, 3, 4])))
    [1, 3]
    >>> list(every_other(iter([])))
    []
    """
