Linked Lists

A linked list is a sequence type that is more efficient than a built-in list for certain operations, such as inserting a value at the front of a long list. Two linked lists that differ only in their first item can share the same rest.

type LinkedList[T] = Link[T] | tuple[()]

@dataclass
class Link[T]:
    first: T
    rest: LinkedList[T] = ()  # rest defaults to an empty linked list

A Link is a non-empty LinkedList, and so has a first and rest. The rest of a Link should always be a linked list: either another Link or ().

You can make a LinkedList by calling Link.

  • Link(4) makes a linked list of length 1 containing 4.
  • Link(4, s) makes a linked list that starts with 4 followed by the elements of linked list s.

Printing a Link shows its elements within parentheses: print(Link(3, Link(4))) displays (3 4).

The second element of s is s.rest.first and the third is s.rest.rest.first.

This linked list visualizer is a great way to understand the structure of a complex linked list.

To check whether a linked list s is empty, use isinstance(s, Link). The VS Code type checker infers that s is a Link and therefore has first and rest attributes only when isinstance(s, Link) is true:

def sum_link(s: LinkedList[int]) -> int:
    """Return the sum of the items in linked list s."""
    if not isinstance(s, Link):
        return 0
    return s.first + sum_link(s.rest)

The type LinkedList[int] describes a linked list whose elements are all integers. A type variable, such as T in def extend[T](s: LinkedList[T], t: LinkedList[T]) -> LinkedList[T], represents any type and expresses that the inputs and output to this function all contain the same type of items.
